4. debug.c-ийн 4 алдааны шалтгаан.
1. is_same :
Шалтгаан: C хэлэнд тэмдэгт мөр (string)-ийг хооронд нь шууд == тэмдгээр харьцуулж болдоггүй санах ойн хаягийг нь шалгадаг тиймээс strcmp функц ашиглаж байж утгаар нь харьцуулах ёстой байсан.

2. reverse_str (Мөр урвуулах функц):
Шалтгаан: Давталт нь тэмдэгт мөрийн урт (n) хүртэл бүтэн гүйснээр байр солигдсон үсгүүд дахин буцаж солигдоод анхны байдалдаа орж байсан. Үүнээс сэргийлж давталт нь яг гол буюу n / 2 хүртэл л үргэлжлэх ёстой.

3. count_vowels (Эгшиг үсэг тоолох):
Шалтгаан: Бүх эгшиг үсгүүдийг хооронд нь логик OR (||) оператороор холбож нэг бүрчлэн тусгайлан шалгахгүй бол буруу тоолох логик алдаа гарч байсан.

4. caesar :
Шалтгаан: Үсгийг шилжүүлэх явцад цагаан толгойн төгсгөл (z) дээр хүрээд давахад автоматаар эргээд a үсэг рүү шилжих циклийг үүсгэхийн тулд заавал % 26 модуль арифметикийг ашиглах шаардлагатай байсан.
