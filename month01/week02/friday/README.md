; 5. eligible? функцэд дутуу дамжуулсан total оролтыг нэмж өгнө.
; 6. Хамгийн чухал суурь шалгуур буюу даалгавар дутуу эсэх эсвэл оноо бага эсэхийг зөв дарааллаар шалгах хэрэгтэй.
